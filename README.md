# 优惠猎手

在美团 / 淘宝闪购 / 京东 上搜大额优惠券的本地工具。零第三方依赖，装了 Python 就能跑。

## 每天怎么用（推荐）

双击 **`本地服务.bat`**，会出现两个网址：

```
这台电脑：  http://127.0.0.1:8788
手机访问：  http://192.168.8.109:8788      ← 手机连同一个 WiFi 就能开
```

手机上把第二个地址**加到主屏幕**，就跟装了个 App 一样。页面右上角有「刷新」按钮，点一下重新抓取。

## 其他用法

双击 **`一键运行.bat`** 打开命令行菜单；或者：

```bash
python run.py serve          # 起本地网站（同上）
python run.py 搜券            # 命令行里直接搜
python run.py 登录 && python run.py 领券    # 领美团专属大额券
```

## 文件地图

```
本地服务.bat        双击启动本地网站（推荐日常用这个）
一键运行.bat        双击打开命令行菜单
run.py              主程序
config.json         数据源配置（可增删改，不用改代码）
coupon_hunter/      程序代码
data/               登录凭证 + 领取历史（登录后才生成）
out/                导出的网页
_site/              给 GitHub Pages 用的构建产物
.github/            GitHub Actions 定时抓取配置
```

## 三条底线

1. 只调官方和第三方公开接口，不爬 App、不绕风控。
2. 手机号和登录凭证只存在本机 `data/auth.json`，代码里没有任何一处往外发。
3. 一个人领自己的券。不做批量账号、不做转发分销。

> 💡 领美团专属大额券需要填一个你自己的「推广渠道号」（美团接口的硬性要求，
> 决定佣金归谁）。本工具**不内置任何人的编号**，留空时该数据源自动跳过，
> 其他功能不受影响。详见 `使用说明.md` 第十一节。
